Sobre o Projeto Secure

O que é o Projeto Secure?

O Projeto Secure é um site educativo desenvolvido para compartilhar conhecimentos sobre segurança digital. Nosso objetivo é explicar situações comuns do ambiente digital, apresentar possíveis riscos e mostrar atitudes simples que ajudam a proteger informações e dispositivos.
